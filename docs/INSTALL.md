# Probar Relevo 0.1.0

Proyecto: https://github.com/jesusvalverde31/relevo

Esta es una versión de desarrollo para probar el flujo principal. No es todavía el lanzamiento comercial.

## Instalar en un móvil Android

1. Copia `relevo-0.1.0-debug.apk` al móvil (Android 8.0 o posterior).
2. Abre el archivo. Si Android lo solicita, permite la instalación desde la aplicación con la que estás abriendo este APK de confianza.
3. Abre Relevo y pulsa “Explorar con ejemplos”, o crea tu primer equipo.
4. En Equipos, abre una ficha y prueba “Prestar”, “Devuelto” y “Enviar a revisión”.

No necesitas cuenta ni conexión. La app no realiza compras.

## Conservar tus datos

En Ajustes puedes guardar/restaurar una copia JSON. Haz una copia antes de desinstalar, cambiar de móvil o instalar una variante firmada con otra clave. Las copias no están cifradas. El APK local y el generado por GitHub Actions pueden tener firmas debug distintas; no alternarlos sin guardar antes los datos.

“Eliminar equipo” conserva su historial; para borrar todo usa los ajustes de almacenamiento de Android. Los ejemplos DEMO pueden eliminarse por separado desde Ajustes de Relevo.

## Estado del producto

Incluye inventario, préstamos, devoluciones, revisiones, búsqueda, historial y copias. Los vencimientos aparecen dentro de la app; todavía no hay notificaciones, fotos, QR, sincronización entre móviles ni cobros.

La [hoja de ruta](https://github.com/jesusvalverde31/relevo/blob/main/docs/ROADMAP.md) y el [borrador de LinkedIn](https://github.com/jesusvalverde31/relevo/blob/main/docs/LINKEDIN.md) están versionados en GitHub.
